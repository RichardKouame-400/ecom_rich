================================================================
MESSAGES D'ERREUR POSSIBLES
================================================================

TERMINAL : "Seller items count: 0"
   → La commande ne contient pas vos produits
   → Exécutez : python creer_commande_test.py

TERMINAL : "Invalid status: None"
   → Le bouton n'envoie pas le statut
   → Problème de formulaire HTML

NAVIGATEUR Console : "Erreur CSRF"
   → Problème de token
   → Rechargez la page (F5)

NAVIGATEUR Console : Aucun message
   → JavaScript bloque peut-être
   → Désactivez JS temporairement
