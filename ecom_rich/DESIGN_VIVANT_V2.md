## 🔍 FONCTIONNEMENT DE LA RECHERCHE

### Barre de Recherche :
1. Utilisateur tape dans le champ
2. Soumet le formulaire (GET)
3. Redirige vers `/produits/?search=terme`
4. Filtre les produits par nom et description
5. Affiche les résultats

### Code Backend :
```python
search = request.GET.get('search')
if search:
    products = products.filter(
        Q(name__icontains=search) | 
        Q(description__icontains=search)
    )
```

## 🎯 MENU DROPDOWN CATÉGORIES

### Fonctionnement :
1. Click sur "Catégories" dans la navbar
2. Menu s'ouvre avec animation fadeInDown
3. Liste de toutes les catégories avec icônes
4. Click sur une catégorie
5. Redirige vers `/produits/?category=ID`
6. Filtre les produits par catégorie

### Avantages :
- ✅ Navigation rapide
- ✅ Toujours accessible
- ✅ Visuellement attrayant
- ✅ Icônes explicites
