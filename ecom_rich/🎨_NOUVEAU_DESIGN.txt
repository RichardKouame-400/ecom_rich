🔍 COMMENT UTILISER LA RECHERCHE
================================================================

1. Tapez dans la barre de recherche
2. Cliquez sur "Rechercher"
3. Les produits sont filtrés automatiquement
4. Recherche dans nom ET description


================================================================
📂 COMMENT UTILISER LE MENU CATÉGORIES
================================================================

1. Cliquez sur "Catégories" dans la navbar
2. Menu s'ouvre avec animation
3. Cliquez sur une catégorie
4. Les produits sont filtrés
5. Retour facile avec "Toutes les catégories"
