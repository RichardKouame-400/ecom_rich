================================================================
🎓 COMMENT PERSONNALISER
================================================================

CHANGER LES COULEURS :

1. Ouvrez : static/css/style.css

2. Modifiez les variables :
   
   :root {
       --primary-color: #votre-couleur;
       --gradient-primary: linear-gradient(...);
   }

3. Sauvegardez et rechargez la page


AJUSTER LES ANIMATIONS :

1. Dans style.css, trouvez :
   
   :root {
       --transition-base: 300ms;
   }

2. Changez la durée selon vos préférences


DÉSACTIVER CERTAINS EFFETS :

1. Ouvrez : static/js/main.js

2. Commentez les sections non désirées
