🎨 COMMENT ÇA MARCHE
================================================================

SYSTÈME INTELLIGENT :

1. Chaque étiquette a un NOM (ex: "Populaire")
2. Le filtre tag_color() cherche le nom
3. Retourne LA MÊME couleur à chaque fois
4. Le filtre tag_icon() cherche le nom
5. Retourne LA MÊME icône à chaque fois

CODE :
   {{ tag.name|tag_color }}  → Dégradé violet pour Populaire
   {{ tag.name|tag_icon }}   → fa-fire pour Populaire


================================================================
💡 AJOUTER DE NOUVELLES ÉTIQUETTES
================================================================

Si vous créez une nouvelle étiquette via l'admin :

2. Ajoutez dans tag_colors :
   'VotreÉtiquette': 'linear-gradient(135deg, #couleur1, #couleur2)',

3. Ajoutez dans tag_icons :
   'VotreÉtiquette': 'fa-votre-icone',

4. Relancez le serveur
