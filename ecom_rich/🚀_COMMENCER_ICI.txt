📋 ETAPE 1 : LANCER LE SERVEUR
================================

   Cliquez sur l'un de ces fichiers :

   ► start_server.ps1   (PowerShell - Recommande)
   ► start_server.bat   (Windows Batch)

   OU tapez dans le terminal :
   
   env\Scripts\activate
   python manage.py runserver


🌐 ETAPE 2 : OUVRIR LE SITE
=============================

   Ouvrez votre navigateur et allez sur :

   ► http://127.0.0.1:8000/

=====================

   1. Double-cliquez sur : start_server.ps1
   
   2. Ouvrez : http://127.0.0.1:8000/
   
   3. Connectez-vous avec : admin / admin123
   
   4. Explorez le site !


💡 ASTUCES
===========

   ⚠️ Si vous voyez "Pillow is not installed" :
      env\Scripts\python.exe -m pip install Pillow

   ⚠️ Pour recreer les donnees :
      python create_sample_data.py

   ⚠️ Pour arreter le serveur :
      Ctrl + C dans le terminal
