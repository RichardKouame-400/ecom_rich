DEPANNAGE RAPIDE :
==================

Probleme : "Pillow is not installed"
Solution : env\Scripts\python.exe -m pip install Pillow

Probleme : Erreur de base de donnees
Solution : Supprimer db.sqlite3, puis :
           python manage.py migrate
           python create_sample_data.py

Probleme : Les images ne s'affichent pas
Solution : Verifier que DEBUG = True dans settings.py


COMMANDES UTILES :
==================

Demarrer le serveur :
   python manage.py runserver

Creer un superutilisateur :
   python manage.py createsuperuser

Creer des donnees d'exemple :
   python create_sample_data.py

Appliquer les migrations :
   python manage.py migrate
