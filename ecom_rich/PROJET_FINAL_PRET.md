## 🚀 GUIDE DE DÉMONSTRATION (Pour Présentation)

### Scénario 1 : Visiteur → Client

```
1. Ouvrir http://127.0.0.1:8000/
2. Montrer la page d'accueil moderne
3. Cliquer sur "Catégories" → Montrer le dropdown
4. Utiliser la barre de recherche
5. S'inscrire comme nouveau visiteur
6. Ajouter des produits au panier
7. Montrer le compteur du panier (badge rouge)
8. Passer une commande
9. Voir "Mes commandes"
```

### Scénario 2 : Vendeur Complet

```
1. Connexion comme vendeur1
2. Aller sur Dashboard → Montrer les statistiques
3. Clic "Commandes" → Montrer la gestion
4. MONTRER LA CONFIRMATION :
   - Commande #3 en "En attente"
   - Clic sur ✓ → Devient "Confirmée" ✅
   - Clic sur 🚚 → Devient "Expédiée" ✅
   - Clic sur ✓✓ → Devient "Livrée" ✅
5. Créer un nouveau produit
6. Upload une image
7. Voir le produit dans le dashboard
```

### Scénario 3 : Administration

```
1. Connexion comme admin
2. Aller sur /admin/
3. Montrer toutes les données
4. Créer une catégorie
5. Voir toutes les commandes
```
