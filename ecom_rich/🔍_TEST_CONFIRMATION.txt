ÉTAPE 1 : PRÉPARER UNE COMMANDE DE TEST
================================================================

A. SE CONNECTER COMME CLIENT :

   2. Cliquez sur "Connexion"
   3. Entrez : client1 / client123

B. AJOUTER DES PRODUITS AU PANIER :
   
   1. Cliquez sur "Tous les Produits"
   2. Choisissez un produit
   3. Cliquez "Ajouter au panier"
   4. Répétez pour 2-3 produits

C. PASSER LA COMMANDE :
   
   1. Cliquez sur "Panier" dans la navbar
   2. Cliquez sur "Passer la commande"
   3. Remplissez l'adresse
   4. Cliquez "Confirmer la commande"
   5. Notez le numéro de commande (ex: #4)

D. SE DÉCONNECTER :
   
   1. Menu utilisateur → "Déconnexion"

================================================================
ÉTAPE 4 : TESTER LA CONFIRMATION RAPIDE
================================================================

Vous devriez voir un tableau avec vos commandes :

┌───────────────────────────────────────────────────────┐
│ N° │ Client │ Date │ Statut │ Total │ Actions        │
├───────────────────────────────────────────────────────┤
│ #4 │ Marie  │ ... │ 🟡 En attente │ 150€ │ [👁️] [✓] │
└───────────────────────────────────────────────────────┘

TEST :
1. Trouvez la commande créée (ex: #4)
2. Son statut doit être "En attente" (badge jaune)
3. Dans la colonne Actions, vous voyez : [👁️] [✓]
4. Cliquez sur le bouton VERT [✓]
5. La page se recharge
6. Le statut devient "Confirmée" (badge bleu)
7. Message vert apparaît en haut


SI LE BOUTON N'APPARAÎT PAS :
   → Le statut n'est pas "pending"
   → Vérifiez le statut dans /admin/

SI LE CLIC NE FAIT RIEN :
   → Faites F12 → Onglet Console
   → Regardez s'il y a des erreurs
   → Faites F12 → Onglet Réseau
   → Cliquez à nouveau
   → Voyez la requête POST

5. Message de succès en haut

================================================================
CODE À VÉRIFIER
================================================================

DANS shop/views.py - Ligne ~415 :

La fonction seller_order_update_status doit :
   1. Vérifier que c'est un vendeur
   2. Récupérer la commande
   3. Vérifier que la commande a des produits du vendeur
   4. Récupérer le nouveau statut du POST
   5. Valider le statut
   6. Sauvegarder
   7. Afficher un message
   8. Rediriger

DANS shop/urls.py - Ligne ~35 :

La route doit être :
   path('vendeur/commande/<int:pk>/statut/', 
        views.seller_order_update_status, 
        name='seller_order_update_status'),
